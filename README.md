# urinary_quest
# 🧬 URINARY QUEST 💀🔥

### 🎮 Videojuego educativo sobre el sistema urinario humano

> **"¿Esto era una tarea? 💀🔥"**

URINARY QUEST es un videojuego educativo creado para aprender de una manera divertida e interactiva sobre el **sistema urinario humano**.

El proyecto combina preguntas educativas, niveles, puntuación, vidas, animaciones, efectos de sonido y un **Boss final** para convertir el aprendizaje en una experiencia tipo videojuego.

---

## 🚀 ¿Cómo se juega?

El objetivo es superar todas las misiones y derrotar al **Señor Desecho**, aprendiendo durante el camino cómo funciona el sistema urinario.

### 🧪 Misiones

* 🫘 **Riñones** — Conoce su función y su importancia.
* 〰️ **Uréteres** — Aprende cómo transportan la orina.
* 🫧 **Vejiga** — Descubre cómo almacena la orina.
* 💧 **Uretra** — Aprende cómo sale la orina del cuerpo.
* 🧪 **Formación y recorrido de la orina**.
* 🧠 **Quiz educativo** con preguntas de selección múltiple.
* 👾 **Boss final** relacionado con los desechos del cuerpo.

---

## 🎯 Objetivo educativo

El juego busca que el jugador comprenda principalmente el recorrido:

**🫘 Riñones → 〰️ Uréteres → 🫧 Vejiga → 💧 Uretra**

También permite aprender sobre:

* Filtración de la sangre.
* Formación de la orina.
* Función de los riñones.
* Nefronas.
* Urea.
* Almacenamiento de la orina.
* Micción.
* Funciones generales del sistema urinario.

## 🌐 ¿Necesita Internet?

**No.**

URINARY QUEST está diseñado para funcionar completamente de manera local.

Todo el juego está contenido en un archivo:

```text
URINARY_QUEST_Sistema_Urinario.html
```

No necesita:

* ❌ Internet
* ❌ Servidor
* ❌ Base de datos
* ❌ Instalación de programas
* ❌ Librerías externas
* ❌ Archivos de audio externos

---

## ▶️ Cómo ejecutar el juego

1. Descarga o clona este repositorio.
2. Abre el archivo:

```text
URINARY_QUEST_Sistema_Urinario.html
```

3. Ábrelo con **Google Chrome**.
4. Presiona:

**🚀 COMENZAR MISIÓN**

¡Y comienza la misión!

---

## 🎮 Controles

| Tecla   | Acción                    |
| ------- | ------------------------- |
| `1`     | Seleccionar opción 1      |
| `2`     | Seleccionar opción 2      |
| `3`     | Seleccionar opción 3      |
| `4`     | Seleccionar opción 4      |
| `ENTER` | Continuar                 |
| `M`     | Activar/desactivar música |

También puedes jugar utilizando el mouse.

---

## 👾 Boss Final

Al finalizar las misiones aparece:

# 👾 SEÑOR DESECHO

El Boss representa los desechos que el organismo necesita eliminar.

Para derrotarlo, el jugador debe responder correctamente preguntas relacionadas con:

* Riñones.
* Orina.
* Urea.
* Nefronas.
* Recorrido de la orina.

Cada respuesta correcta reduce la vida del Boss.

Cuando su vida llega a **0**, se desbloquea la pantalla:

# 🏆 MISIÓN COMPLETA

## 🎨 Diseño

El videojuego utiliza una estética inspirada en videojuegos futuristas:

* 🌌 Fondos oscuros.
* ⚡ Colores neón.
* ✨ Partículas.
* 💡 Efectos luminosos.
* 👾 Elementos tipo ciencia ficción.
* 🎮 Interfaz gamer.

La intención es hacer que un tema académico se sienta como una misión de videojuego.

---

## 🔊 Audio

Los efectos de sonido se generan directamente mediante **Web Audio API**.

Esto permite que el proyecto tenga sonidos para:

* Respuestas correctas.
* Respuestas incorrectas.
* Ataques al Boss.
* Victoria.
* Eventos del juego.

No se utilizan canciones comerciales ni archivos de audio con copyright.

**Explorar → Pensar → Responder → Aprender → Avanzar → Derrotar al Boss**
